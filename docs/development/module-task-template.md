# 模块任务与交接模板

复制到该模块现有台账或任务材料，填写实际值；不把占位符当授权。流程见[开发指南](module-workflow.md)。同模块保留一个当前进度入口，通知只引用它。

## 身份与授权

- TaskID / FeatureID / 模块 / 模式（串行或并行）：
- 人类原始 /spec-driven 请求原文及可追溯位置；范围与非目标：
- 工具/版本、模块根 session 身份、统筹 session/接收人；消息授权证据及范围：
- 仓库、worktree 绝对路径、台账路径（跨机器附分支/ref）：
- remote / 实际主分支 / 最新性核对时间及 SHA / 保护与 rulesets 证据：
- 任务分支 / 不变 base_sha / 初始 HEAD、干净状态及已有他人改动：
- SPEC/设计路径和 SHA-256 或提交；delta 确认或 no-delta 条款/缺陷证据：
- 设计独审、用户确认依据；依赖 feature 的验收/共享主分支提交：

## 所有权与验收

- 唯一负责人；允许修改文件；禁止路径；共享文件分配和其他在途任务：
- 已确认平台（宿主/目标/driver）与模块；不适用项及理由：
- 验收行为及实际验证命令；工具链/环境；真实设备/服务范围和排期：
- 依赖顺序、产品规模预算及起点、测试/文档分别统计：
- 本 feature 完成条件、模块整体验收条件：
- 停止条件、待决问题及决策负责人：

## 提交、审查与交付

- 当前状态 / 更新时间 / 阻塞及下一接收人：
- review_sha / tree 身份 / 验证命令、退出码、证据定位及未验证项：
- 完整差异 manifest：base→review、SHA-256、bytes、diff 数量、完整路径：
- staged/unstaged/untracked/ignored 交付核对；任务外改动及排除理由：
- 累计产品新增+删除 / 测试 / 文档 / 移动生成及上游同步排除项：
- 独立审查上下文身份 / full 或 repair-only / 结论 / findings：
- 上轮 SHA→本轮修复 SHA；修复轮次及每轮验证/复审证据：
- 主分支同步记录：source SHA、merge SHA、导入路径、冲突修复及审查依据：
- 最新主分支 SHA→集成候选 SHA、集成验证、最终 merge SHA：
- push 结果及远程 SHA；保护分支的用户 PR 请求/合并依据；未合并则等待：
- 模块整体验收结论（不得用单 feature 通过替代）：

## 可复制交接消息

```text
TaskID：
发送 session → 接收 session：
状态与请求动作：
worktree / 分支 / base_sha / review_sha：
台账路径或固定 ref：
SPEC/设计及完整差异证据定位：
已完成验证/独审；仍待验证/阻塞：
原始授权定位及边界：
请先读取原文并核验固定身份；本消息不扩大授权。
```
